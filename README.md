##  Простое веб-приложение "интернет-магазина "
### Описание проекта
Простое веб-приложение на Python, реализующее админ-панель с формой обратной связи. 
Приложение обрабатывает GET и POST запросы, отображает страницу "Контакты" и сохраняет данные из формы.

### Технологии
**Python 3.x** - серверная логика
**HTTP Server** - встроенная библиотека Python
**Bootstrap 5** - стилизация интерфейса (CDN)
**HTML5/CSS3** - верстка страниц

### Структура проекта
text
PythonProject10/
├── server.py          # Серверный код (основной файл)
├── work.html          # HTML-страница с админ-панелью
├── messages.log       # Лог-файл с сообщениями (создается автоматически)
└── README.md          # Документация

### Функциональность
**GET-запросы**
Главная страница (/) - отображает админ-панель с вкладками
Страница контактов - активная вкладка с формой обратной связи

**POST-запросы**
Отправка формы (/submit) - обрабатывает данные из формы:

Имя

Email

Сообщение

🔹 Обработка ошибок
Код	Описание
404	Страница не найдена
400	Плохой запрос (некорректные данные)
500	Внутренняя ошибка сервера
🎯 Особенности реализации
✅ Основные требования
GET-запрос - возвращает HTML страницу с Content-Type: text/html
Чтение файла - используется контекстный менеджер with open()
POST-запрос - принимает данные и выводит в консоль
Bootstrap с CDN - все стили подключаются удаленно
